How to create table
--------------------------------------------------
create table users(
  id int PRIMARY key AUTO_INCREMENT, 
  fullname varchar(128) not null, 
  email varchar(128) unique not null, 
  gender char(1) not null, 
  dob date not null, 
  height decimal(3,2) check (height>0), 
  salary int default 10000, 
  detail text, 
  created_at timestamp default CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP   
)

How to insert row into table?
-----------------------------------
to insert row in table, use insert into command. it has 2 version 
1) version 
syntax 
insert into <tablename> values ()

insert a row into users 
------------------------------------------------------------------
insert into users values (0,'Yashvi Trivedi','yashvi@gmail.com','F','2006-08-13',5.5,1250000,'GMIT student currently pursing MCA',CURRENT_TIMESTAMP)

2 version 
syntax 
insert into <tablename> (fieldlist) values ()
