How to create table
--------------------------------------------------
create table users(
  id int PRIMARY key AUTO_INCREMENT, 
  fullname varchar(128) not null, 
  email varchar(128) unique not null, 
  gender char(1) not null, 
  dob date not null, 
  height decimal(3,2) check (height>0), 
  salary int default 10000, 
  detail text, 
  created_at timestamp default CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP   
)

How to delete rows from table 
Delete rows from table without condition (all rows delete)
syntax 
delete from tablename
example 
delete from users 

Delete rows from table with condition (selected rows delete)

syntax 
delete from tablename where relational_expression 

example 
1) delete user whose id is 109.
SQL

delete from users where id = 109
2) delete users whose height is equal to or below 5.20
delete from users where height<=5.20

delete row from  users table whose name is Alok Desai
delete from users where name = "Alok Desai"

How to empty table & reset primary key 
syntax 
truncate table <tablename>
example 
truncate table users 


how to remove table and all data it has 
---------------------------------------
syntax 
drop table <tablename>

example 
drop table products 


how to update rows in tables?
-------------------------------------------------
syntax 

update <tablename> set field_1=value [,field_2=value] [,field_n=value] [where <condition>]

example
------------- 
update users set fullname to 'Divya Patel' email to divya.patel@gmail.com and gender to female of user whose id is 1 

SQL 
update users set fullname = 'Divya Patel', email = 'divya.patel@gmail.com', gender='F' WHERE id=1

update user increase salary of all users by 5000 rupees 
update users set salary = salary + 5000

update users decrease salary by 2 percentage 
update users set salary = salary * 0.98

How to rename table ? change table name 
rename table <oldtablename> to <newtablename>


example 
rename table users to persons
rename table persons to users

how to change table structure ?
add new column into table 
ALTER TABLE table_name ADD column_name datatype(size);
alter table users add remarks char(255)

change column name/column's datatype/size of column in table?
----------------------------------------------------
to change column name 
ALTER TABLE table_name RENAME COLUMN old_column_name TO new_column_name;
alter table users rename column detail to remarks

to change datatype of existing column 

ALTER TABLE table_name MODIFY COLUMN column_name new_datatype(size);
alter table users modify column remarks varchar(512)

to add column into table 
alter table table_name add column column_name datatype(size)
alter table users add column notes char(255)

to drop existing column 
ALTER TABLE table_name DROP COLUMN column_name;
alter table users drop column notes 

-------------------------------------------------
 
how to fetch data from table?
to fetch data from table, we use select statement

syntax 
select * | <column-list> from tablename [where condition] [group by fieldname] [having condition] [order by fieldname] [limit start,offset]

examples 
1) fetch all rows and all column from users table 

select * from users 

2) fetch selected fields 
fetch all users' id,fullname,email,date of birth, gender 

select id,fullname,email,dob,gender from users 
select id,fullname,email,date_format(dob,'%d-%m-%Y') as birth_date,gender from users

how to filter records/row 

fetch users detail (all fields) of only those users who are male 
select * from users where gender = 'm'

fetch user's name and salary of those users whose salary is below 20000
select fullname,salary from users where salary<20000
